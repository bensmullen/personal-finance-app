The table distinguishes canonical vocabulary from executable support. **Partial** means a reusable seam or generic representation exists, with the missing ordinary contract still required. **Absent** means the family has no admitted product execution path. A canonical enum alone never means supported. No named D2 family is optional. The repository contains D1/T1A seam evidence but no existing dedicated D2 catalog/test directory at the starting commit.
